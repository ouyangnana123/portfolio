01

重命名 GitHub 仓库

必做 · 1 分钟
⚠️
为什么必须改？

你的仓库名是 -（单个连字符），GitHub Pages URL 会变成 https://ouyangnana123.github.io/-/，URL 末尾的横杠既不专业，也可能被某些工具误判。改为 portfolio 后 URL 干净好记。

1在 GitHub 上重命名

  • 打开 github.com/ouyangnana123/-/settings
  • 顶部 Repository name 输入框 → 清空 → 输入 portfolio
  • 点击页面底部的绿色按钮 Rename
github.com/ouyangnana123/-/settings
Repository nameportfolio ✏️
Rename点击即生效

2更新本地 remote 地址

仓库改名后，本地 git 还指向旧地址，需要更新：

git remote set-url origin https://github.com/ouyangnana123/portfolio.git git remote -v # 应该看到两行 origin 都指向 portfolio.git，不是 -.git
💡
小知识

GitHub 重命名后会自动设置旧 URL 的重定向，所以理论上不改 remote 短期也能 push。但建议立即改，避免日后混淆。

视频路径自适应原理

技术细节 · 可跳过

核心问题

HTML 里写相对路径 videos/xxx.mp4，浏览器解析时会基于当前页面 URL 的目录来拼接：

部署位置页面 URL相对路径解析结果正确性
GitHub Pages 子路径/portfolio//portfolio/videos/xxx.mp4✅ 正确
GitHub Pages 根目录//videos/xxx.mp4✅ 正确
本地 file://D:/0毕设/D:/0毕设/videos/xxx.mp4✅ 正确

大多数情况下相对路径就够用。但为了极端场景下的稳健性，我在 videos.js 顶部加了 SITE_PREFIX 与 resolveVideoSrc()：

// 自动检测部署路径前缀 window.SITE_PREFIX = (function () { var p = window.location.pathname; var lastSlash = p.lastIndexOf("/"); if (lastSlash >= 0 && /\.[a-z0-9]+$/i.test(p.slice(lastSlash + 1))) { p = p.slice(0, lastSlash); // 去掉文件名 } if (p.length > 0 && p.charAt(p.length - 1) === "/") { p = p.slice(0, -1); // 去掉结尾斜杠 } return p || ""; // 根目录返回 ""，子路径返回 "/portfolio" })(); // 把相对路径解析成带前缀的绝对路径 window.resolveVideoSrc = function (src) { if (/^(https?:|data:|blob:)/i.test(src)) return src; // 已是绝对 URL if (src.charAt(0) === "/") return src; // 已带绝对路径 return window.SITE_PREFIX + "/" + src; // 拼前缀 };

这样无论部署到哪个路径，HOSTED_VIDEOS 里的相对路径写法都一样，index.html 渲染视频时会自动调用 resolveVideoSrc() 解析。

添加新视频的流程

# 1. 把新视频放进 videos/ 文件夹 # （建议 ≤ 25MB，文件名英文小写，如 campus-tour.mp4） # 2. 编辑 videos.js，在 HOSTED_VIDEOS 数组里加一条 window.HOSTED_VIDEOS = [ { src: "videos/project-demo-2026-05-14.mp4", title: "...", desc: "..." }, { src: "videos/campus-tour.mp4", title: "校园游览", desc: "..." } # ← 新增 ]; # 3. 提交并推送 git add . git commit -m "add campus-tour video" git push # 4. 等 1~2 分钟，刷新网页即可看到新视频
FAQ

常见问题

Q1: 推送后网页没更新？

GitHub Pages 有 1~2 分钟构建延迟。检查仓库 → Actions 标签，看是否有名为 pages-build-deployment 的 workflow 正在跑。绿色对勾代表构建完成。

Q2: 视频在国内加载很慢？

GitHub Pages 服务器在国外，国内访问确实慢。两个替代方案：

  • 方案 A：把视频上传到 B 站，HTML 里改用 <iframe> 嵌入 B 站播放器
  • 方案 B：改用 Cloudflare Pages 部署，全球 CDN 加速，但单文件 25MB 上限

Q3: 能用自己的域名吗？

可以。仓库 → Settings → Pages → Custom domain → 输入你的域名 → Save。然后在域名服务商处加 CNAME 记录指向 ouyangnana123.github.io，再勾选 Enforce HTTPS。

Q4: 想更新简历内容怎么改？

所有简历内容（个人简介、教育、实习、项目、技能）都在 index.html 里，直接用任何编辑器（VS Code / Notepad）打开修改文字，然后：

git add . && git commit -m "update resume" && git push

Q5: 仓库要不要设为 Public？

GitHub Pages 免费版要求仓库必须 Public。免费账号下的 Private 仓库无法启用 Pages。如果你不希望代码公开，可以：

  • 升级 GitHub Pro（$4/月）→ Private 仓库也能用 Pages
  • 或改用 Cloudflare Pages（支持 Private 仓库且免费）
